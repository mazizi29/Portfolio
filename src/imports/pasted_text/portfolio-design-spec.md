Design a complete high-end personal portfolio website UI for an Informatics student with a strong graphic design background.

The portfolio should position the person primarily as an INFORMATICS STUDENT who can DESIGN AND BUILD digital experiences, rather than as a generic graphic designer.

Core positioning:
"Design-minded Informatics Student"
Supporting specialties:
UI/UX Design · Front-End Development · Visual Design

The visual direction should be minimal, editorial, sophisticated, modern, and highly aesthetic. Use a predominantly monochrome visual system: black, off-white, white, and neutral gray. Avoid excessive gradients, colorful UI, glassmorphism, neon effects, excessive shadows, and overly decorative elements.

The design should feel like a combination of:

* premium editorial portfolio
* modern product designer portfolio
* minimal developer portfolio
* contemporary graphic design portfolio

Prioritize typography, whitespace, grid, visual hierarchy, composition, and high-quality imagery.

Use a strong modern sans-serif typeface for the primary interface, with optional subtle serif typography for selected editorial accents.

================================
DESIGN SYSTEM
=============

Color palette:

Primary:
#0A0A0A

Background:
#F7F7F5

White:
#FFFFFF

Secondary text:
#6F6F6F

Border:
#DCDCDC

Use monochrome as the dominant visual language.

Typography:
Use a modern sans-serif such as Inter, Geist, Manrope, or similar.

Use large display typography for hero sections.

Use a strict spacing system based on 4px / 8px increments.

Use generous whitespace.

Use thin borders instead of heavy shadows.

Border radius should be subtle and consistent, preferably 0–8px.

================================
INTERACTION / UX
================

Public portfolio:

* subtle image hover zoom
* text/link underline animation
* smooth page transitions
* subtle reveal animations
* project image transitions
* sticky navigation
* active navigation state

Avoid:

* excessive cursor effects
* unnecessary parallax
* excessive scroll animations
* loading screens
* flashy gradients
* excessive 3D effects

The website should feel fast, intentional, and professional.
